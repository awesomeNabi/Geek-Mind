# MAGIC_MINI Migration Notes

> The active Ubuntu 22.04 / ROS 2 Humble deployment intentionally excludes ARX. See [HUMBLE_SETUP.md](HUMBLE_SETUP.md) for the pinned RealSense build, Go2 Livox bridge, navigation safety gates, and acceptance procedure. The notes below describe the older migration target.

MAGIC_MINI is a reduced migration target for:

`config/unitree_go2_koala_fetch_single_mode.json5`

An optional Mid360 navigation variant is also included:

`config/unitree_go2_koala_fetch_single_mode_autonomy_mid360.json5`

## Keep

- `src/`: runtime framework plus dynamically loaded plugins. The target config uses the runtime loader, actions, inputs, backgrounds, hooks, providers, LLM plugins, Zenoh messages, and Unitree SDK package.
- `config/unitree_go2_koala_fetch_single_mode.json5`: native-navigation runtime variant and safe default.
- `config/unitree_go2_koala_fetch_single_mode_autonomy_mid360.json5`: optional FAST-LIO + autonomy_stack_go2 navigation variant.
- `config/schema/`: JSON schema validation for single and converted multi-mode configs.
- `config/prompts/koala_fetch_single_mode_prompt.txt`
- `config/prompts/koala_fetch_single_mode_autonomy_mid360_prompt.txt`
- `config/prompts/voice_task_decomposition_prompt.txt`
- `service/__init__.py`, `service/yolo_sdk.py`, `service/grasp_sdk.py`: external YOLO/grasp service clients imported by the ARX X5 grasp executor.
- `service/unitree_native_slam/company_001_locations.json`: native navigation location map referenced by the config.
- `service/unitree_native_slam/company_20260630_100336_autonomy_locations.json`: Mid360 map-frame goals.
- `service/unitree_native_slam/autonomy_mid360/`: portable FAST-LIO, Open3D localization, autonomy planner, bridge sources, Docker build, and guarded navigation scripts.
- `service/models/sherpa-onnx-kws-zipformer-wenetspeech-3.3M-2024-01-01/`: wake-word model that exists on this machine and matches the current `.env` style overrides.
- `system_hw_test/arx_x5_motion_zenoh_bridge.py`: ARX X5 ROS2-to-Zenoh motion bridge used by the stack script.
- `scripts/start_magic_mini_stack.sh`: mini startup wrapper, defaulting to this project and the single-mode config.
- `pyproject.toml`, `uv.lock`, `.python-version`, `.env.example`: reproducible Python environment inputs.

## Exclude

- `backup/`, `logs/`, `recordings/`, caches, generated bytecode.
- `frontend/`, docs, broad examples, and unrelated configs.
- `service/Kokoro-FastAPI` and full `service/GraspAnything`; the target config calls an external YOLO endpoint instead of running those services locally.
- Most `tests/` and hardware scratch scripts.

## Run

```bash
cd /home/unitree/MAGIC_MINI
cp .env.example .env
# Fill DASHSCOPE_API_KEY in .env.
scripts/start_magic_mini_stack.sh start
```

To start the Mid360 variant explicitly:

```bash
# One-time image build after cloning or after ROS service source changes.
bash service/unitree_native_slam/autonomy_mid360/scripts/build_image.sh

KOALA_FETCH_CONFIG=unitree_go2_koala_fetch_single_mode_autonomy_mid360 \
  scripts/start_magic_mini_stack.sh start
```

The startup wrapper creates or starts the portable `magic_mini_mid360_nav` container for the Mid360 variant. The native configuration remains the default. The Mid360 variant enables real-robot goals and stands the Go2 up before each navigation action; it does not change posture at process startup or shutdown.

Direct runtime start for debugging. The dds extra is required by this Unitree config:

```bash
cd /home/unitree/MAGIC_MINI
export CYCLONEDDS_HOME=/home/unitree/cyclonedds_ws/install/cyclonedds
uv run --extra dds src/run.py unitree_go2_koala_fetch_single_mode
```
